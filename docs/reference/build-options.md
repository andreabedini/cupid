# Build options and install layout

The meson options that configure a Cuddles build, and where `ninja install`
puts things.

## Setting options

Options are given as `-Dname=value` to `meson setup`, or changed later
with `meson configure build -Dname=value`.  `meson configure build`
with no arguments lists every option with its current value.

## Cuddles options

| Option | Type | Default | Meaning |
|---|---|---|---|
| `cuddlesdir` | string | `libdir/cuddles` | Directory for the Cuddles libraries |
| `libraries` | boolean | `true` | Build the Haskell libraries |
| `readline` | feature | `auto` | Command-line editing with GNU readline or libedit; `enabled` fails if neither is found, `disabled` never uses one |
| `char-encoding` | `utf8`, `locale`, `none` | `utf8` | Encoding for character I/O; see [Character encoding](../explanation/character-encoding.md) |
| `profiling` | boolean | `false` | Heap profiler: the `-d` option, output in `profile.hp` for hp2ps |
| `timer` | boolean | `false` | Time every evaluation, for benchmarking Cuddles itself |
| `debug-code` | boolean | `false` | Keep assertions enabled and add the `+D` toggle that prints generated bytecode |
| `tag-checks` | boolean | `false` | Assert at the type checker's entry points that what is passed as a type, kind or predicate has that shape (see `src/tagcheck.h`); a failure is an internal error naming the function |
| `internal-prims` | boolean | `false` | Experimental primitives that expose Cuddles internals |
| `stack-dumps` | boolean | `false` | On stack overflow, print the objects under evaluation |
| `path-canonicalization` | boolean | `false` | Convert file names to absolute normal form |
| `small-banner` | boolean | `false` | One-line start-up banner |
| `explain-instance-resolution` | boolean | `false` | Add the `:xplain` command and the `+x` toggle |
| `dont-panic` | boolean | `false` | Leave fatal signals to the debugger instead of returning to the prompt |

Each option sets one or two macros in the generated `config.h`.  The
platform facts are not options: they are written down in
`src/sysdeps.h` and the generated `src/platform.h`, and the type widths
and constants for the base library are computed at build time by
`libraries/tools/mksysconfig.c`.

## Standard meson options used

| Option | Default | Meaning |
|---|---|---|
| `prefix` | `/usr/local` | Install prefix |
| `bindir` | `bin` | Programs, under the prefix |
| `libdir` | `lib` or `lib64` | Parent of the default `cuddlesdir` |
| `buildtype` | `debugoptimized` | Compiler optimisation and debug info |
| `c_std` | `c23` | The C dialect; the sources need it |

## Install layout

With the default prefix:

| Path | Contents |
|---|---|
| `/usr/local/bin/cuddles` | The interpreter |
| `/usr/local/bin/runcuddles` | The script runner |
| `/usr/local/bin/fficuddles` | The FFI stub compiler |
| `/usr/local/lib/cuddles/packages/cuddles/` | The `Prelude` and the `Cuddles.*` modules |
| `/usr/local/lib/cuddles/packages/base/` | The `base` library |
| `/usr/local/lib/cuddles/include/HsFFI.h` | Header for FFI stubs |
| `/usr/local/lib/cuddles/demos/` | Example programs |
| `/usr/local/lib/cuddles/docs/` | This documentation |
| `/usr/local/lib/cuddles/README.md`, `License`, `Credits` | |
| `/usr/local/share/man/man1/cuddles.1` | Manual page |

`ninja -C build install` honours `DESTDIR`.  The library directory can
be moved with `-Dcuddlesdir=DIR`; the compiled-in default search path and
`CUDDLESDIR` default follow it.

## Build tree layout

| Path | Contents |
|---|---|
| `build/src/cuddles`, `runcuddles`, `fficuddles` | The programs |
| `build/src/config.h`, `platform.h` | Generated headers |
| `build/libraries/cuddlesdir/` | The assembled libraries, in install layout |
| `build/libraries/mksysconfig` | The generator for the platform-dependent library parts |

## Targets

| Command | Effect |
|---|---|
| `ninja -C build` | Build everything |
| `ninja -C build install` | Install |
| `ninja -C build clang-tidy` | Run the curated static analysis |
