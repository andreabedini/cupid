Building Hugs on Windows
========================

The meson build is written to support Windows (MinGW-w64 or MSVC) but
has not yet been verified there.  The platform-specific choices are in
src/sysdeps.h, meson.build (shared-library flags, install paths) and
packages/base/mkHsBaseConfig.c; the library bootstrap script
libraries/tools/bootstrap needs a POSIX shell such as the one in MSYS2
or Git for Windows.

The intended procedure is the same as on Unix (see unix.txt):

    meson setup build
    ninja -C build
    ninja -C build install

The first person to build on Windows will probably need to fix a few
things in the files named above.  The WinHugs GUI under src/winhugs
and the .NET bridge under src/dotnet are not built by meson; they kept
their own project files from the 2006 release.
