## [0.1.0] - 2026-10-27

### Added

- Type check f $ x as f x
- Accept tuple sections
- Accept type operators
- Derive Generic
- Derive via a type, and by the newtype strategy
- Make Applicative a superclass of Monad and give fail its own class
- Make Semigroup a superclass of Monoid
- Define the Prelude's folds by Foldable and Traversable
- Add the base modules and functions of the last two decades
- Add the base modules that transformers needs
- Give the Prelude's Word its instances, and Data.Bits FiniteBits
- Solve Typeable for every type from its structure
- Rewrite Control.Exception with the Exception class
- Add Data.Data, and derive Data
- Add GHC.Stack, and type synonyms for constraints
- Add standalone deriving, and derive Monad-like classes via a type
- Add polymorphic type synonyms and kinded forall binders
- Find the libraries next to the executable
- One `cupid` command: a file runs its `main`, `-i` loads files at the prompt, `--ffi` compiles foreign-import stubs

### Fixed

- Expand ~/ in :load, :also and :edit paths
- Expand a bare ~ in path arguments
- Reject a directory passed to :load
- Test for a regular file with S_ISREG in readable
- Accept a left section whose operand is an infix expression
- Improve the context of an instance used to reduce a constraint
- Infer derived contexts through functional dependencies
- Accept hiding an unexported name, and give Word its Bits with Data.Bits
- Keep bit indices, shift counts and pointer arithmetic defined in C
- Never derive Typeable via another type, and stop on recursive newtypes
- See through synonyms that drop their arguments when unifying
- Infer only contexts of classes applied to type variables
- Derive newtype a class of type constructors via the wrapped type less its parameters
- Print expressions the same way in every build
- Accept a top-level pattern binding that binds no variables
- Report a type and a class of one name as ambiguous
- Report C {} that omits a strict field of an unlabelled constructor
- Build the interpreter with MinGW-w64
- Check the C stack against its real size
- Tell GNU readline apart from WinEditLine
- Build the base library on Windows
- Close a handle once hGetContents has read all of it
- Keep the drive letter in a search path entry
- Quote the arguments of the programs Cupid runs
- Bound inferred-context reduction by the -c cutoff
- Read only a first-line #! as blank
- Make $$ work when input is piped
- Spell "arguments" in the :? help
- Link "Edit this page" to the main branch
